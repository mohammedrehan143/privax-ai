# Prompt 01 — Architecture planning

Read the blueprint and produce an implementation-ready architecture proposal.

Include:
- Monorepo structure and module boundaries.
- Desktop and local web strategy with shared backend.
- Local model runtime abstraction.
- Document parser/OCR choices.
- SQLite metadata, lexical index and optional vector index.
- Agent contracts, schemas and orchestration state machine.
- Local storage, encryption and deletion lifecycle.
- Loopback security and offline network boundary.
- 8 GB CPU-only execution plan.
- Dependency/licensing risks.
- Test strategy and measurable performance plan.

Do not write the application yet. Identify trade-offs and decisions requiring approval.
