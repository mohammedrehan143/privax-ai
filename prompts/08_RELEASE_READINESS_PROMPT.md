# Prompt 08 — Release readiness

Evaluate the implementation against every item in `docs/11_ACCEPTANCE_CRITERIA.md`.

Produce:
- Pass/fail matrix with test evidence.
- Offline network-egress evidence.
- Supported OS and hardware matrix.
- Measured Tier 1 performance on an 8 GB CPU-only device.
- Model and dependency license inventory.
- Known limitations and risks.
- Packaging and offline provisioning instructions.
- Rollback/update procedure.
- Demo script using synthetic non-sensitive documents.

Do not mark failed, untested or unverified items as passed. Do not claim enterprise readiness without
an independent security review.
