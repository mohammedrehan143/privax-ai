# Prompt 02 — Build the foundation

Implement the approved repository skeleton and foundation only.

Requirements:
- Desktop shell and local web interface can both start.
- Shared local API starts on loopback only.
- Health, hardware capability and runtime status endpoints exist.
- UI clearly distinguishes backend unavailable, model unavailable and offline status unknown.
- All assets are bundled locally; no remote fonts/CDN/analytics.
- Add structured logging with sensitive-content redaction.
- Add unit tests and a one-command development workflow.
- Do not implement fake document Q&A. Mark unimplemented features honestly.

Run the tests and document setup on Windows first, while keeping cross-platform boundaries clean.
